## 📌 О программе

Заполнение 30–50 грамот вручную в графических редакторах или Word отнимает часы рутинного труда, приводит к опечаткам и «съехавшим» шрифтам. 

**Certiflow** полностью автоматизирует этот процесс:
* Вам **не требуется** устанавливать Python или сторонний софт — приложение работает как единый автономный файл `.exe`.
* Имена автоматически выравниваются по базовой линии синей полосы на бланке.
* Длинные составные фамилии автоматически ужимаются по ширине, чтобы не налезать на иллюстрации.
* Готовый PDF-файл сохраняется с разрешением **300 DPI** — при печати на принтере буквы остаются четкими и гладкими.

1. Перейдите в раздел **[Releases](https://github.com/BelGray/Certiflow/releases)** репозитория и скачайте файл `Certiflow_v1_0_0.exe`.

3. Скопируйте столбец с фамилиями из школьного журнала или Excel (`Ctrl + C`) и нажмите в программе **«📋 Из буфера»**.
4. Проверьте посадку имени на бланке в окне справа.
5. Нажмите большую зеленую кнопку **«Сгенерировать PDF»**.
6. Готовый файл сразу откроется для отправки на печать.

## 📖 Подробное руководство пользователя

### 3.1. Обзор рабочего окна

Интерфейс разделен на две основные зоны:
* **Слева (Панель управления):** ввод и редактирование фамилий, переключатели форматирования, прогресс выполнения и запуск генерации.
* **Справа (Живой холст):** интерактивная интерактивная миниатюра бланка грамоты, показывающая результат в реальном времени.
* **Центральный разделитель:** вертикальная серая полоска между колонками, за которую можно тянуть мышкой для изменения масштаба холста.
* **Внизу:** раскрывающееся меню тонких настроек бланка и контакты автора.

### 3.2. Способы добавления участников

В программе предусмотрено три варианта ввода имен:

1. **Ручной ввод:**
   Вбивайте ФИО прямо в поля списка. Чтобы добавить еще одного участника, нажмите кнопку **«➕ Имя»** вверху списка. Чтобы удалить участника — нажмите красный крестик **«✕»** справа от строки.
2. **Вставка из буфера обмена:**
   Быстрый перенос десятков записей из любых таблиц или документов.
3. **Импорт из текстового файла:**
   Если список передан в блокноте `.txt`, его можно загрузить через «Продвинутые настройки».

---

### 3.3. Вставка списка из Excel / Таблиц

Самый быстрый способ оформить грамоты на целый класс:

1. Откройте Excel, Google Таблицы, МЭШ или электронный журнал.
2. Выделите столбец с фамилиями учеников (например, 25 человек) и нажмите `Ctrl + C`.
3. В окне программы нажмите синюю кнопку **«📋 Из буфера»**.
4. Программа мгновенно создаст строки под каждого ученика и распределит их по порядку.

> 💡 **Совет:** Если в буфере уже были пустые строчки, программа автоматически очистит их перед вставкой.

---

### 3.4. Автоматическое исправление регистра (ФИО)

Учителя часто присылают списки с разным форматированием: кто-то пишет капсом (`ИВАНОВ ИВАН`), кто-то со строчной буквы (`петров петр`), а кто-то с лишними пробелами между словами.

* Включенная галочка **«Форматировать ФИО»** приводит каждую запись к типографскому стандарту: `Иванов Иван` (лишние пробелы удаляются, первая буква каждого слова становится заглавной, остальные — строчными). Двойные фамилии через дефис (`Мамин-Сибиряк`) форматируются корректно.

---

### 3.5. Интерактивный предпросмотр и разделитель

Справа от списка находится интерактивный макет грамоты:
* Как только вы вводите или меняете имя первого участника в списке — надпись на грамоте справа **сразу обновляется**.
* **Управление масштабом:** Наведите курсор на вертикальную полоску между левой и правой частью окна (курсор превратится в `⟷`). Зажмите левую кнопку мыши и потяните влево, чтобы увеличить грамоту, или вправо, чтобы освободить место под список.
* Грамота масштабируется адаптивно: края, фотоаппарат, книги и подпись директора **никогда не срезаются** и остаются в поле зрения на 100%.
* **Быстрый сброс:** Двойной клик по полоске-разделителю возвращает ширину панелей к стандартному удобному соотношению.

### 3.6. Создание и печать PDF

1. Нажмите зеленую кнопку **«Сгенерировать PDF»**.
2. В процессе сборки синяя шкала прогресса покажет статус (например, `Стр. 14 из 28...`).
3. По завершении появится окно об успешном сохранении.
4. Если отмечен пункт **«Открыть PDF после создания»**, готовый документ мгновенно откроется в вашей стандартной программе для просмотра PDF (Adobe Reader, Яндекс Браузер, Edge и т.д.).
5. Нажмите `Ctrl + P` в открывшемся окне и отправьте файл на школьный принтер.

### 3.7. Продвинутые настройки

Нажатие на кнопку **«⚙ Продвинутые настройки ▼»** открывает дополнительную панель:

| Параметр | Назначение | Значение по умолчанию |
| :--- | :--- | :--- |
| **📄 Импорт .txt** | Загрузка участников из текстового файла со списком в столбик (UTF-8 / CP1251). | — |
| **Выбрать шаблон** | Загрузка собственного фонового бланка грамоты (`.png`, `.jpg`). | Шаблон Школы №2122 |
| **Выбрать шрифт** | Подключение любого шрифта конкурса (`.ttf`, `.otf`). | `TT Masters Black` |
| **Цвет текста** | Кнопка с палитрой для выбора оттенка фамилии под дизайн грамоты. | `#182B49` (Тёмно-синий) |
| **Координата X** | Горизонтальная позиция центра надписи в пикселях. | `Авто` (строго центр листа) |
| **Линия Y** | Точная высота базовой линии синей черты бланка. | `765` |
| **Размер шрифта** | Начальный размер букв в пунктах. | `75` |
| **Имя файла** | Название создаваемого PDF-документа (спецсимволы `\/:*?"<>|` отфильтруются автоматически). | `Грамоты_Школа2122` |
| **Папка** | Каталог, куда будет сохранен готовый итоговый PDF. | Папка с программой |

> 💾 **Автосохранение:** Все параметры из этого меню автоматически сохраняются в файл `config.json` рядом с программой. При следующем запуске вам не придется настраивать координаты или папки заново.

### 3.8. Ответы на частые вопросы (FAQ)

**Вопрос: Что делать, если фамилия очень длинная (например, «Константинопольский-Александров»)?**  
*Ответ:* Ничего делать не нужно. В программе работает встроенный алгоритм авто-подгонки: если надпись превышает 70% ширины бланка, кегль шрифта автоматически плавно уменьшается до тех пор, пока строка гарантированно не поместится между рамками.

**Вопрос: Почему буквы не прыгают вверх-вниз, если у одной фамилии есть хвосты («у», «р», «д»), а у другой нет?**  
*Ответ:* Программа выполняет привязку текста по базовой типографской линии (`baseline anchor`). Буквы «стоят» ножками ровно на синей черте, а хвостики свисают под нее, как при рукописном заполнении.

**Вопрос: Нужен ли интернет для работы программы?**  
*Ответ:* Нет. Все операции рендеринга, верстки и сборки PDF выполняются локально на вашем компьютере.

## 💻 Для разработчиков

### 4.1. Архитектура и структура файлов

Проект построен с соблюдением разделения ответственности (Separation of Concerns). Ядро генерации отвязано от интерфейса и может использоваться независимо.

```text
Certiflow/
├── assets/                          # Статические ресурсы по умолчанию
│   ├── diploma_template.png         # Исходный бланк грамоты (1054 x 1492)
│   └── tt_masters_fonts/
│       └── TTMasters-Black.ttf      # Акцидентный шрифт награждения
├── core/                            # Ядро бизнес-логики
│   ├── __init__.py                  # Версионирование (SemVer)
│   ├── generator.py                 # Движок Pillow: рендеринг, авто-фитинг, экспорт PDF
│   ├── config.py                    # Менеджер персистентности конфигурации (JSON)
│   └── utils.py                     # Хелперы: DPI-резолвер путей, нормализация, санитайзер
├── ui/                              # Представление (GUI)
│   ├── __init__.py
│   └── app.py                       # Главное окно CustomTkinter, Viewport Canvas, потоки
├── requirements.txt                 # Зависимости среды разработки
└── main.py                          # Точка входа для запуска и Nuitka-сборки
```

#### Ключевые архитектурные решения:
* **Потокобезопасность:** Рендеринг тяжелых страниц выполняется в фоновом демоне `threading.Thread`. Возврат сигналов в GUI (прогресс-бар, открытие файлов, диалоги) осуществляется исключительно через потокобезопасную очередь событий `self.after(0, ...)`.
* **Event Coalescing (Схлопывание событий):** Перемещение разделителя панелей троттлится до 45–50 FPS через `after(20)`, исключая насыщение очереди событий Windows и фризы графического интерфейса.
* **Двухуровневый рендеринг:** Полноразмерный рендеринг имени на бланке кэшируется в оперативной памяти и пересчитывается только при изменении данных. При изменении размера панелей выполняется только легковесный ресайз готового кадра в RAM.

### 4.3. Сборка автономного .exe через Nuitka

Программа компилируется непосредственно в машинный код на C++ с помощью Nuitka, что обеспечивает моментальный старт, защиту от реверс-инжиниринга и отсутствие ложных срабатываний антивирусов.

1. **Установите компилятор и библиотеку сжатия:**
   ```bash
   pip install nuitka zstandard
   ```
   *(При первом билде Nuitka предложит автоматически загрузить portable-компилятор MinGW64 — подтвердите ввод буквой `yes`).*

2. **Запустите команду компиляции:**
    ```bash
    python -m nuitka --onefile \
    --windows-console-mode=disable \
    --windows-icon-from-ico=assets/icon.ico \
    --enable-plugin=tk-inter \
    --include-package=PIL \
    --include-package-data=customtkinter \
    --include-data-dir=assets=assets \
    --windows-file-version=1.0.0 \
    --windows-product-name="Certiflow" \
    --windows-company-name="bel_gray" \
    --output-dir=dist \
    main.py
    ```

3. **Результат:**
   В каталоге `dist/` появится полностью автономный файл `main.exe` размером ~25–35 Мб, готовый к передаче заказчику.

```json
    "right_col_width": 420
}
```
